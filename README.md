# Claude Skills Field Guide
### R365 R&D · Payroll & Workforce

A practical, interactive guide to building with Claude Skills at R365 — written for engineers, QA, designers, and PMs working in the 3-person pod model.

**→ [View the live guide](https://schlingmanj.github.io/claude-skills-guide/)**

---

## What this is

This guide covers:
- What Claude Skills are and the right mental model for using them
- How to write, test, and iterate on a skill
- How Skills and Agents work together
- R365-specific guardrails for the Payroll & Workforce domain — where miscalculated output has real compliance consequences

It's designed for a mixed audience: people who have never touched Claude Code and people who have. It assumes baseline technical comfort but explains the Skills/Agents concepts from scratch.

## Who it's for

Anyone in the R365 R&D org working with Claude tools — pod members (engineers, QA, designers, PMs) and team leads who need to evaluate and guide the work.

## How to update this guide

1. Edit `index.html` locally or directly in GitHub
2. Go to the repo → **Add file → Upload files** (or edit in place)
3. Upload the new version, write a short commit message describing what changed
4. GitHub Pages will automatically reflect the update within a minute or two
